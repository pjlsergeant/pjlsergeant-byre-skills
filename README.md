# pjlsergeant-byre-skills

Skill packages for [byre](https://github.com/pjlsergeant/byre), published by
pjlsergeant. Each directory under `skills/` is one package: a `skill.toml`
distribution manifest (generated by `byre skill pack` -- it carries the
exhaustive payload list with sha256 hashes) plus the payload files beside it.

Install commands are **tag-pinned** (`/v1.0.0/`, never `/main/`) and carry the
package digest, so the bytes you get are the bytes this tag was published
with. A git tag is a convention, not an integrity guarantee -- the `--digest`
pin is what makes the command end-to-end verifiable. Installing grants
nothing: a package only takes effect when a box's config enables it.

## Packages

### pjlsergeant/devlog

Dev-workflow conventions: diary, devlog dir, scratch volume.

```
byre skill install https://raw.githubusercontent.com/pjlsergeant/pjlsergeant-byre-skills/v1.0.0/skills/devlog/skill.toml --digest sha256:9ecb65b18386ceea0dc54b7bb040b42e29a9872ab8fed4f9b1f86d5562926c12
```

Baseline CLI tools for every box: ripgrep, fd, tree, less, procps, vim, and
friends.


### pjlsergeant/claude-skills-pocock

Matt Pocock's Claude Code skill collection
([github.com/mattpocock/skills](https://github.com/mattpocock/skills), MIT),
repackaged as byre payloads: a firstrun hook syncs each skill into the Claude
state volume at launch. Upstream's `code-review` is renamed
`pocock-code-review` (name clash with a harness built-in). See
`skills/claude-skills-pocock/LICENSE` for upstream's license and copyright.

```
byre skill install https://raw.githubusercontent.com/pjlsergeant/pjlsergeant-byre-skills/v1.0.0/skills/claude-skills-pocock/skill.toml --digest sha256:40771e3556f6b1d970cdae086665963c8f23538db48ad796bedc2e5111fa6ef2
```

## Publishing a new version

1. Edit the package's payload files; bump `version` in its `[package]` block.
2. Regenerate the manifest: `byre skill pack <id> > skills/<name>/skill.toml`
   (pack prints the new digest).
3. Commit, tag, push. Update the pinned commands here with the new tag and
   digest.

Manifests are relative: payloads are fetched from the same directory as the
`skill.toml` that names them, so raw GitHub URLs work as-is.
